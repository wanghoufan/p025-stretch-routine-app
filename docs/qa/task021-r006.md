## 2. DoD 逐条取证

### D1 时钟不再读 `Date.now()`
代码层：`MonotonicClock` 生产路径走 `modules/stretch-runtime` 的 `SystemClock.elapsedRealtime()`；模块缺席（Expo Go / Jest / web）回退 RN `performance.now()`；`Date.now()` 在计时路径上不再出现。`minSdk=24` 与 `BOOT_COUNT` 的 API 24 起点恰好对齐，无需版本分支。

### D2 真 boot 身份
`BootInfo` 读 `Settings.Global.BOOT_COUNT`。实测同 boot 内杀进程前后 `boot_count` 均为 `26`（未变），真重启后变为 `27`。

### D3 真机跳钟验证（四组全过）
