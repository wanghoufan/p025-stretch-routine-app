## §5 计划者原本应前置发现的缺口

按「本可一句话写进 Day 1 契约」排序：

1. **核心承诺与发布条件必须排进第一个 milestone，或书面降级**。SPEC 自己写了 SC-004 是硬条件，却没把它排进任何 milestone，这是计划层的自相矛盾。
2. **技术尖刺的判定必须附环境基线**。「离线可用＝满足」在 eSpeak 设备上为真，在 mibrain 设备上为假；写出「满足」时必须同时写「在什么设备、什么系统版本、什么网络状态下为真」。
3. **第三方语音的商用授权要在选型当轮查**。xiao_ya 听感最好却因 BZNSYP Non-commercial 永久出局——这类结论应当在 09-17 就得出，而不是 09-27。

## §6 UI / 布局 / 导航 / 页面密度 / 高频操作的可复用经验

以下均为**条件性规则**，不是通用强制（反例见 §9）。

1. **统计入口挂首页内容区，不加第 4 个常驻 tab**（HD-3）。理由：回看是低频动作，加 tab 等于把「回看」提升为第二主功能。条件：主功能只有一个（跑流程）时成立；多并列功能区不适用。
2. **批量录入优先于多屏表单**。SC-001 明确「不做 5 个独立全屏表单」，落成 `BatchActionInput`（一行一个动作）。这是「高频操作密度」的正确解法：新建流程的动作录入是最高频、最易劝退的环节。
3. **深色 + 磁贴降低视觉噪点**（Motion Core：`#041B3D` + 磁贴，`userInterfaceStyle: dark` 固定）。纯粹外观层的替换可以零业务改动完成——这是**先功能后换皮**的正确顺序，也是本项目少见的干净改动。
4. **筛选 chips 必须跟随当前活动场景、支持交集、同屏去重、命中区 ≥48dp**。B-4 的三条修正全部来自真机：搜索态点非活动组头只收起不切场景；活动场景 0 命中时 chips 悬空；单字 chip 42.5dp 过小。
5. **快照不可变**：`RoutineStep` 保存播放值，改动作库不影响已存流程（FR-015）。这条不是 UI 规则，但决定了「编辑」与「播放」两个界面的耦合度。
6. **Runner 不吃 params、只听 ActiveSession**：源流程被改名/删除后仍能继续（R019）。
7. **设置页必须「最小」**：US7 原文「Settings MUST remain minimal」；语速可调、5 秒预警每步一次；「逐秒倒数播报」明确不做是产品决策而非缺陷。
8. **语音类产品必须有「测试语音」按钮**（09-24 加入）。这是本项目里性价比最高的一个 UI 元素：它把「设备侧引擎/音量/线缆/投屏」四类问题的排查从「跑完整流程才发现没声」压缩到「点一下就知道」。
9. **完成页数字与统计同源同单位同舍入**（HD-6）。改口径会让数字变小，必须配说明文案（「只统计实际动作时间，暂停和转场不计」），且 Runner 顶部若仍含转场要标「流程已用（含转场）」，不得冒称统计值。

## §9 适用范围、反例与「不能推广为通用规则」的部分

### 9.1 适用范围

本文件结论主要适用于：**移动端（尤其 Android 国产 ROM）单机离线优先的工具型 App**，且核心价值依赖某一种系统能力（语音、通知、定位、传感器）。这类项目的共性风险是「**核心能力由系统/厂商决定，产品承诺却由产品侧单方面写下**」。

### 9.2 反例与边界

- **「V1 先做亮屏、后台顺延」不等于可以不做**。方案 A 本身没错，错在没有排期与书面豁免。反过来：把后台能力硬塞进 V1 也未必对——如果用户确实接受亮屏，砍掉承诺并明说，同样是合格决策。
- **「不做计次」不是普适结论**。健身计数类产品（组数/次数是核心指标）必须建模；本项目属拉伸跟练，口播替代成立的前提是「用户不需要事后数据」。
- **「深色固定主题」不是通用最佳实践**。本项目 `userInterfaceStyle: dark` 是为了品牌一致性；面向大众的工具类应跟随系统。
- **「统计不加 tab」只适用于单主功能产品**。多业务 App 需要并列导航。
- **「治理脚手架铺包」的教训不能推广为「不要治理模板」**。问题是**所有权未定义**，不是模板本身。
- **「离线优先」在不同产品里门槛不同**。本项目语音离线在体积/授权/音质/UX 四维都无免费午餐，这个结论**只对中文 TTS 成立**，不能推广为「所有离线能力都不值得做」。

### 9.3 明确不能从本项目推出的结论

- 不能推出「Expo Go 适合做原生特性验证」——`HANDOFF` 明确「Expo Go 不能作原生特性验收」。
- 不能推出「小米设备不能做语音 App」——真机联网播报是通的，问题在离线与默认引擎设置。
- 不能推出「documentation-heavy 就是坏事」——本项目 QA/review 落盘与真机证据是真实产出；问题在**同一批文档里产品叙事被治理叙事覆盖**。
